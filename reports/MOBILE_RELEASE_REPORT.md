## الفحص الأمني (تطبيقات الجوال)

ما نُفّذ:
1. **mobsfscan 0.4.5 مع Semgrep** (قواعد OWASP MASVS لـ Java/Kotlin/Swift وملف Manifest).
2. **detect-secrets** على مجلدات android وios وstore: لا أسرار.
3. **مراجعة يدوية للكود** على نقاط الهجوم المعروفة في تطبيقات WebView.

نتائج mobsfscan:

| القاعدة | الخطورة | القرار |
|---|---|---|
| StrandHogg 2.0 | ERROR | **أُصلح** بـ `taskAffinity=""`. الأداة تظل تُبلغ لأنها لا ترى targetSdk 36 في Gradle — إنذار خاطئ موثّق في `.mobsf` |
| allowBackup غير محدد في debug | WARNING | **أُصلح** |
| hidden_ui (View.GONE) | ERROR | إنذار خاطئ: يخفي شريط التحميل ولوحة عدم الاتصال، لا بيانات حساسة |
| cleartext في network config | INFO | في نسخة debug فقط، لـ localhost و127.0.0.1 |
| SSL pinning، Certificate Transparency، كشف الروت، SafetyNet، منع لقطات الشاشة، tapjacking | INFO | قرارات تصميم: لا تثبيت شهادات (تجديد Let's Encrypt قد يعطّل التطبيق)، وأندرويد 12+ يمنع لمسات التطبيقات المتراكبة |
| iOS | — | لا نتائج |

المراجعة اليدوية — الحمايات القائمة في التطبيقين:
- التنقل داخل التطبيق لمصدر المنصة فقط (scheme + host + port)، مع اختبارات لروابط مثل `example.test.evil.test` و`user@host` و`blob:` و`javascript:`.
- لا تجاوز لأخطاء شهادات TLS. HTTP ممنوع في الإصدار.
- جسر الصفحة يقبل الرسائل من الإطار الرئيسي ومصدر المنصة فقط، بحد 10MiB وقائمة أنواع ملفات محددة وتنظيف أسماء الملفات.
- جلسة السائق مشفرة: Android Keystore (AES-GCM) وKeychain بخاصية ThisDeviceOnly، وتُمسح عند إعادة تثبيت تطبيق iOS.
- طلبات السائق تمنع إعادة التوجيه، فلا تُرسل الجلسة لخادم آخر. معرّفات المسارات تُرمّز (اختبار `../admin`).
- صور المستندات في iOS يُعاد ترميزها JPEG، فتُحذف بيانات الموقع منها قبل الرفع.
- فحص الويب (Web Inspector / WebView debugging) في نسخ التطوير فقط.

حدود الفحص: فحص ساكن ومراجعة كود، ولم يُجرَ اختبار اختراق ديناميكي على جهاز حقيقي، ولا فحص للخادم ضمن هذا العمل. تقرير الخادم في `reports/SECURITY_REPORT.md`.

## ما لا يمكن إكماله من المستودع (يلزم منك)

1. **مفتاح رفع أندرويد** وأسرار GitHub الأربعة — الخطوات في `docs/MOBILE_RELEASE.md`.
2. **حساب Google Play Developer** (25 دولارًا مرة واحدة) وإقرار خدمة الموقع الأمامية مع فيديو.
3. **حساب Apple Developer** (99 دولارًا سنويًا) ومفتاح App Store Connect API وأسراره الأربعة.
4. **لقطات الشاشة** للمتجرين، وحسابات تجريبية للمراجعين على المنصة المستضافة.
5. **مانع إطلاق:** المنصة نفسها بيئة اختبار بدفع وتوصيل تجريبيين (انظر `FINAL_ACCEPTANCE_REPORT.md`). المتجران يرفضان عادة تطبيقًا يبيع منتجات حقيقية بدفع وهمي. يلزم مزود دفع حقيقي قبل الإرسال للمراجعة.
6. **خطر مراجعة Apple 4.2:** التطبيقات المعتمدة على WebView قد تُرفض لقلة الوظائف الأصلية. شاشات السائق الأصلية والموقع والإشعارات تقلل هذا الخطر ولا تلغيه.
