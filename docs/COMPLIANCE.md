# متطلبات قبل الإطلاق التجاري

مراجعة مصادر رسمية بتاريخ 29 أكتوبر 2026. هذه نقاط تنفيذ تحتاج تحديد النشاط والعقود، وليست فتوى أو اعتمادًا نظاميًا. لا تعني إضافة زر «معتمد» توثيقًا حكوميًا.

| المجال | ما يلزم حسمه | المصدر الرسمي |
|---|---|---|
| التجارة الإلكترونية | هوية جهة التشغيل، الإفصاح عن السعر والسياسات والشكاوى وتوثيق المتجر وأهلية الأسرة بحسب نشاطها | [وزارة التجارة: الأنظمة والأدلة](https://mc.gov.sa/ar/ECC/pages/default.aspx)، [توثيق التجارة الإلكترونية](https://mc.gov.sa/ar/mediacenter/ConsumerCorner/Pages/E-commerce.aspx) |
| حماية البيانات | جهة التحكم والأساس النظامي وحقوق أصحاب البيانات ومدد الاحتفاظ والمعالجون والنقل خارج المملكة | [سدايا: نظام حماية البيانات الشخصية](https://dgp.sdaia.gov.sa/wps/portal/pdp/knowledgecenter/details/PDPL) |
| توصيل الطلبات | تحديد انطباق تنظيم نشاط توصيل الطلبات وأهلية المنشأة والسائقين وإجراءات التشغيل | [الهيئة العامة للنقل: اللائحة التنفيذية](https://www.tga.gov.sa/WebSiteFile/f1711830-fb1b-4569-a6c1-7f4778f9e02c) |
| الدفع | مزود مرخص وعقد سوق وتوزيع مستحقات؛ لا يتحول السجل الداخلي إلى محفظة أو صلاحية للاحتفاظ بأموال الغير | [البنك المركزي: الجهات المرخصة](https://sama.gov.sa/ar-sa/Supervision/LicenseEntities/pages/licensed_payment_service_providers_companies.aspx)، [اللائحة التنفيذية للمدفوعات](https://rulebook.sama.gov.sa/en/implementing-regulations-payments-and-payment-services-law) |
| الفوترة والضرائب | تحديد صفة كل بائع والمنصة، وانطباق ضريبة القيمة المضافة والفوترة الإلكترونية ومراحل التكامل | [زاتكا: أدلة الفوترة الإلكترونية](https://www.zatca.gov.sa/ar/E-Invoicing/Introduction/Guidelines/Pages/default.aspx) |
| منتجات منظمة | تصاريح الغذاء والمنتجات والحساسية وسلامة النقل والعطور وفق النشاط والمنطقة؛ لم تُراجع حالة منشأة بعينها | يستلزم إجراء مراجعة مع الجهات المختصة والمستشار قبل تمكين بيع كل فئة |

السياسات العربية الحالية مسودات. لم تحدد جهة تشغيل حقيقية أو قنوات تواصل رسمية أو مدد احتفاظ نهائية. لا يطبق النظام فوترة ZATCA أو VAT تلقائيًا. يجب منع استقبال بيانات وأموال عملاء حقيقيين حتى استكمال هذه القرارات والإجراءات واختبارها.
