| التوصيل | عروض ورفض وقبول ذري ورحلة واحدة ورمزا استلام وتسليم وتعثر وإعادة إسناد إدارية، مع شرط عودة الطلب بعد الاستلام | شركة توصيل ومسارات ورسوم فعلية تنتظر المزود والاتفاق والتنفيذ والاختبار |
| الدفع | واجهة مزود ومحاكاة وتوقيع وتكرار وفشل واسترداد جزئي/كلي وسجل أحداث | لا موصل مالي تجاري أو Sandbox تابع لبوابة؛ يحتاج اختيار مزود سوق وتنفيذ موصله |
| السجل المالي | فصل منتجات وتوصيل واستردادات، تقارير يومية لـ90 يومًا وCSV، عدم اختلاق صافي أرباح | رسوم وتسويات فعلية وضرائب وفوترة تنتظر النموذج والاعتماد والربط |
| الاشتراكات | باقات وحد منتجات وشهري/سنوي اختياري وتجربة قابلة للتهيئة وفواتير وفشل/نجاح محاكاة وتجديد بإشعار وانتهاء | لا خصم تلقائي أو تحصيل حقيقي |
| Telegram | ربط مؤقت وخاصية صورة ثم نص خلال30 دقيقة أو تعليق، مسودة واعتماد صريح وحدود استخدام وإزالة تكرار وoutbox | بوت حي وWebhook وإرسال خارجي لم تُهيأ أو تختبر |
